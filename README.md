## ⚙️ FCFS Scheduling & Banker’s Algorithm

**Operating Systems Scheduling & Deadlock Avoidance Simulation**

An individual Operating Systems project exploring **FCFS CPU scheduling and Banker’s Algorithm** through step-by-step simulation and analysis.

The FCFS experiment analyzes **12 processes**, waiting times, turnaround times, execution order, and the convoy effect. The Banker’s Algorithm experiment calculates the **Need Matrix**, evaluates system safety, and determines the safe sequence **P2 → P4 → P1 → P3**.

**Areas:** Operating Systems • CPU Scheduling • FCFS • Deadlock Avoidance • Banker’s Algorithm
