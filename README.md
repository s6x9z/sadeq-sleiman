### ❤️ [Heart Disease Prediction](./heart-disease-prediction/)

**Machine Learning Classification Using Random Forest and Decision Tree**

A machine learning project that predicts heart disease using patient data. I implemented and compared Random Forest and Decision Tree classifiers using accuracy, precision, recall, and F1-score.

### 🏠 [House Price Prediction with Deep Neural Networks](./house-price-deep-learning/)

**Deep Learning Regression & Architecture Comparison**

An individual deep learning project using the Ames Housing dataset to explore house-price prediction through data preprocessing, feature engineering, target transformations, Linear Regression, and neural networks with different depths.

The project also explores model generalization and uses PCA to investigate hidden neural-network representations.

**Areas:** Python • TensorFlow • Keras • Deep Learning • Regression • Data Analysis

### 🔐 [Cipher Forensics & Attack Recommendation Engine](./cipher-forensics/)

An individual Python-based cybersecurity project that analyzes ciphertext using frequency and pattern analysis, estimates the most likely classical cipher family, explains its classification, and recommends an appropriate cryptanalysis approach.

It supports Caesar, Monoalphabetic Substitution, and Transposition ciphers.

**Areas:** Python • Cybersecurity • Cryptography • Cryptanalysis • Pattern Analysis

## 📚 Additional Projects

A Java console application that simulates flight reservations, availability searches, cancellations, and reservation history. It uses a custom Linked List for active reservations, a Stack for cancelled reservations, and a Priority Queue for reservation ordering.

**Areas:** Java • Object-Oriented Programming • Data Structures • Algorithms

### ⚖️ [Criminal Justice System Database](./criminal-justice-system/)

A relational database project covering offenders, crimes, cases, arrests, and law-enforcement officers. Includes ER modeling, relational schema design, SQL queries, and an HTML/CSS interface prototype.

**Areas:** SQL • Database Design • ER Modeling • Relational Databases • Web Development

### 🚑 [Hospital Emergency Triage System](./hospital-triage/)

Two implementations of a hospital triage system. The Java version explores QuickSort, QuickSelect, pivot strategies, and runtime comparisons. The Python version focuses on patient management, symptom-based triage, sorting, searching, editing, discharge, and statistics.

**Areas:** Java • Python • Algorithms • Data Structures • QuickSort • QuickSelect

### ⚙️ [FCFS Scheduling & Banker's Algorithm](./operating-systems-scheduling/)

An Operating Systems project exploring FCFS CPU scheduling and Banker's Algorithm through simulation and analysis. The FCFS experiment examines 12 processes, waiting times, turnaround times, execution order, and the convoy effect. The Banker's Algorithm experiment evaluates system safety and determines the safe sequence P2 → P4 → P1 → P3.

**Areas:** Operating Systems • CPU Scheduling • Deadlock Avoidance • Resource Allocation • Algorithms
