# ☕ Hospital Emergency Triage System — Java

## CMPS441 Algorithms Implementation

This version of the Hospital Emergency Triage System focuses on **algorithm design and performance analysis using Java**.

### Implemented Features

- QuickSort by patient severity
- QuickSelect for finding the k-th most critical patient
- Randomized pivot selection
- Deterministic Median-of-Three pivot selection
- Performance comparison
- Manual patient entry
- Random patient generation
- Patient search
- Severity statistics
- Four-level triage classification
