# 🐍 Hospital Emergency Triage System — Python

## CMPS445 CPL Implementation

This version of the Hospital Emergency Triage System focuses on **Python programming concepts and patient-management functionality**.

Patients are automatically assigned a triage level based on symptom keywords and can be managed through a terminal-based menu.

### Implemented Features

- Add patients
- Automatic triage-level assignment
- View waiting list
- Sort by urgency and age
- Filter by triage level
- Search by patient name or symptom
- Edit patient information
- Recalculate triage after symptom changes
- Discharge patients
- Display statistics
- Input validation
- Triage-help menu

### Python Concepts

- Functions
- Lists
- Dictionaries
- Conditionals
- `for` loops
- `while` loops
- List comprehensions
- Lambda expressions
- Sorting
- Searching
- Input/output
- Validation
